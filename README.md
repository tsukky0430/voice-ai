# Voice AI（プロトタイプ v0.1）

話しかけると Claude が考えて、落ち着いた声で返事をする Web アプリです。
PC・スマホ・タブレットのブラウザで動きます。

## できること
- AI のビジュアルはデザイン画像そのもの。回転はせず、ふわふわと浮遊する（背後の光だけ、聞いている・話している状態に合わせて強弱がつく）
- 話し方は「コーチング型」：すぐ答えを出さず、問いかけで本当にやりたいことを引き出し、必要なときにコードも書く
- マイクボタン（または球体）をタップ → 話す → Claude が返事を読み上げる
- **ハンズフリー**：返事が終わると自動で聞き取りを再開。画面も点いたままになる
- 話している途中でタップすると、止めてすぐ聞き取りに切り替わる（割り込み）
- コードは画面にだけ表示し（コピーボタン付き）、声では「コードは画面に表示しています」と伝える
- **会話の一覧**：複数の会話を保存し、選んで続きから話せる（右下の「会話」）
- **claude.ai から取り込み**：claude.ai の書き出しファイル（zip / conversations.json）から会話を選んで取り込み、続きを深められる。会話をコピーして貼り付ける方法も可
- **使用量**（左上）：予算に対して何%使ったかと、リセットの日時を表示。タップで詳細（金額・トークン・直近1回の料金）
- **設定**（右上の歯車）：モデル（Fable 5.1 / Opus 5.5 / Sonnet 5.5 / Haiku 4.5）、エフォート、予算、声の種類・速さ・高さ、合言葉
- 文字入力、PC ではスペースキーで話しかけ
- 合言葉（APP_PASSCODE）で、他人に使われないよう保護

## 公開手順（Vercel）
1. このフォルダを GitHub の新しいリポジトリにアップロード
2. Vercel で「Add New → Project」からそのリポジトリを選ぶ
   - Framework Preset は **Other** のまま、ビルド設定は変更不要
3. 「Environment Variables」に次を追加してデプロイ
   | 名前 | 値 |
   |---|---|
   | `ANTHROPIC_API_KEY` | Claude の API キー（https://console.anthropic.com で発行） |
   | `APP_PASSCODE` | 好きな合言葉（初回アクセス時に入力を求められます） |
   | `CLAUDE_MODEL` | 省略可。アプリで選ばなかったときのモデル。既定は `claude-sonnet-5-5` |
   | `AI_NAME` | 省略可。AI の名前 |
4. 発行された URL をスマホで開き、マイクを許可すれば会話できます
   - iPhone は Safari の共有メニュー →「ホーム画面に追加」でアプリのように使えます

## claude.ai の会話を取り込むには
1. claude.ai の「設定 → プライバシー → データを書き出す」を実行（数分〜でメールにダウンロードリンクが届く）
2. ダウンロードした zip を、このアプリの「会話 → claude.ai から取り込む」で選ぶ
3. 一覧から続きを話したい会話を選ぶ（選んだ会話だけがこの端末に保存される）

※ claude.ai の会話を外部から直接読み出す仕組みはないため、書き出しファイルか貼り付けを使います。

## ファイル構成
- `index.html` / `style.css` / `app.js` … 画面・球体の動き・音声入出力
- `api/chat.js` … Claude とやり取りするサーバー側の処理（API キーはここだけで使う）
- `orb.webp` … AI のビジュアル（元画像の市松模様を取り除いて透過化したもの）

## 調整したいとき
- AI の名前：`app.js` 冒頭の `CONFIG.name`（画面表示）と環境変数 `AI_NAME`（AI の自己認識）
- 読み上げの速さ・高さの初期値：`app.js` 冒頭の `rate` / `pitch`（端末ごとの変更は設定画面から）
- 性格・話し方・コーチングの度合い：`api/chat.js` の `systemPrompt()`
- 浮遊の幅・速さ：`app.js` の「浮遊」の部分

## 使用量の表示について
- 表示しているのは、このアプリが Claude API に支払う料金（API の料金表から計算した目安）を、設定した予算で割った割合です
- claude.ai のプラン（Pro・Max）の「現在のセッション ◯% 使用済み」とは別物で、互いに影響しません
- 記録は端末ごと。正確な請求額は console.anthropic.com の Usage で確認

## 既知の制限（次の段階で改善予定）
- 声はブラウザ標準の読み上げ（端末により声質が変わる）。自然な声の音声合成サービスへの切替は Step 4
- 音声認識はブラウザ標準のため Firefox は非対応（Chrome / Safari / Edge は対応）
- iPhone はバックグラウンドや画面ロック中は動作しない
- 会話履歴は端末のブラウザ内にだけ保存（端末間の同期は Supabase 導入時に対応）
